# Python Tutorial Repository

This repository contains a comprehensive, hands-on Python tutorial series, progressing from beginner to intermediate concepts. It is organized by day and topic, with practical exercises, projects, and cheat sheets for libraries like NumPy and Pandas.

## Structure & Topics Covered

### Day 1: Working with Variables in Python to Manage Data
- Introduction to Python
- Variables, input, and string manipulation
- Project: Brand Name Generator

### Day 2: Understanding Data Types and Manipulation
- Data types, type conversion, and mathematical operations
- f-strings
- Project: Tip Calculator

### Day 3: Control Flow and Logical Operators
- if/else, logical operators (and, or, not)
- Nested conditions
- Project: Treasure Island (text adventure)

### Day 4: Randomisation and Python Lists
- Random module, lists, indexing, and list operations
- Project: Rock Paper Scissors

### Day 5: Python Loops
- for and while loops
- Range, sum, and list comprehensions
- Project: Password Generator

### Day 6: Python Functions & Karel
- Defining and calling functions
- Arguments, indentation, and return values
- Project: Escaping the Maze

### Day 7: Hangman
- String/list manipulation, game logic
- Project: Hangman Game

### Day 8: Function Parameters & Caesar Cipher
- Function parameters, keyword arguments
- Project: Caesar Cipher (encryption/decryption)

### Day 9: Dictionaries, Nesting, and the Secret Auction
- Dictionaries, nesting lists/dicts
- Project: Secret Auction Program

### Day 10: Functions with Outputs
- Return values, multiple returns, docstrings
- Project: Calculator

### Day 11: Blackjack Capstone Project
- Capstone: Blackjack game implementation

## NumPy Tutorial
- Basics, array creation, and types

## Pandas Tutorials
- DataFrames: creation, loading, accessing, filtering

## How to Use
- Each folder contains Jupyter Notebooks (`.ipynb`) with explanations, code, and exercises.
- Start from Day 1 and progress sequentially for a structured learning path.
- Explore the NumPy and Pandas tutorials for data science essentials.

## Requirements
- Python 3.12+
- Jupyter Notebook or JupyterLab
- Install required libraries: `numpy`, `pandas`, etc.
